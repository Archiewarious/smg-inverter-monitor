# Мониторинг гибридного инвертора SMG II (GSIKE и клоны) + виджет для Windows

Свой мониторинг вместо облака SmartESS: данные остаются дома, всё работает в локальной сети.
*English: a local-only monitor for SMG II-type hybrid inverters with an EyBond Wi-Fi module, plus a Windows tray widget that switches the PC to power-saving mode when the mains go off.*

Проверено на одном инверторе: **GSIKE GSK-2KW-12V** (клон SMG II) с модулем «WPBLE DTU PlugPro» (EyBond), прошивка модуля 8.50.12.3, литиевая АКБ 12,8 В. На других моделях номера регистров могут отличаться.

## Что внутри

| Файл | Что делает |
|---|---|
| `monitor.py` | Сервис: принимает подключение модуля, раз в 5 с читает регистры, пишет историю в SQLite, отдаёт веб-страницу и JSON, ведёт журнал событий |
| `eybond.py` | Разговор с модулем EyBond (оба диалекта) и Modbus RTU |
| `index.html` | Веб-страница: графики, сводка по дням, циклы заряда, настройки инвертора, журнал, CSV |
| `widget.pyw` | Значок в трее и панель (Windows): остаток времени от АКБ, экономия при пропаже сети, яркость монитора |
| `PowerMode.ahk` | Переключатель схем питания Windows (нужен AutoHotkey v2); виджет вызывает его сам |
| `redirect.py` | Разово отправляет модулю команду «подключайся к этому ПК» |

## Только чтение

В инвертор ничего не пишется: единственный Modbus-запрос в коде — чтение (`0x03`). Команд записи в инвертор и модуль в коде нет.

## Быстрый старт

Нужен Python 3.12+ (только стандартная библиотека), ПК в той же сети, что и модуль.

1. Скопируйте `config.example.json` в `config.json` и заполните: `bind` и `redirect_to` — адрес ПК, `module_ip` — адрес модуля, `web_token` — длинная случайная строка (она часть адреса страницы). `module_pn` — серийный номер модуля (если указан, чужие подключения отклоняются).
2. Запустите `python monitor.py`.
3. Модуль подключится сам, если `auto_redirect` включён (сервис шлёт ему UDP-команду `set>server=IP:PORT;` на порт 58899, пока модуль не подключён). Либо один раз выполните `python redirect.py`.
4. Страница: `http://<адрес ПК>:8900/<web_token>/`.

Прошивка модуля сама не переподключается после обрыва, поэтому `auto_redirect` нужен: сервис вернёт модуль за секунды.

## Виджет (Windows)

`pythonw widget.pyw` — значок в трее. Зелёный — сеть есть, красный — нет, жёлтый — авария, серый — нет данных. По щелчку — панель: мощность, АКБ, остаток времени, ползунок яркости монитора (DDC/CI), ручной выбор режима и настройки таймеров.

При пропаже сети виджет включает схему «Экономия энергии» (экран, диски, сон и гибернация по вашим таймерам, яркость монитора вниз), а когда сеть вернулась, возвращает всё как было. Остаток времени считается по ёмкости `battery_ah` и счёту ампер-часов.

Автозапуск: запись в реестре `Run` на новых Windows 11 бывает пропущена, надёжнее задание планировщика на вход пользователя.

## Безопасность

- Страница отдаётся по **HTTP** и защищена только токеном в адресе. Держите сервис в домашней сети, **не выставляйте порты в интернет**.
- Облако производителя (SmartESS) продолжает работать параллельно и умеет менять настройки инвертора. Чтобы это закрыть, запретите модулю выход в интернет на роутере.
- Ничего из `config.json` (токен, адреса, серийный номер), базы и журналов в репозиторий не попадает, это проверяет `.gitignore`.

## Отказ от ответственности
